# Mehrab Halalkhor Portfolio — V2

GitHub Pages portfolio with certificate gallery, achievements, and Python article.

### Publish
1. Create a public GitHub repository.
2. Upload everything in this folder to the repository root.
3. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Replace `YOUR_EMAIL@example.com` in `index.html` with your real email.

The uploaded Python resource was provided as a PSD file, so this package keeps the original PSD and also includes a PDF version generated from its first page.
